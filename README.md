## 🚀 Projetos em Destaque

### 🌎 Piauí para o Mundo *(Vencedor Estadual - SEDUC-PI)*
> Plataforma de inteligência territorial, dados abertos e projeção do ecossistema econômico, tecnológico e turístico do Piauí — projeto premiado com imersão no **IMPA Tech**.

- **Stack:** `TypeScript` `React` `Vite` `TailwindCSS` `Leaflet` `GeoJSON`
- **Arquitetura:** Integração de APIs e renderização vetorial otimizada de malhas territoriais geoespaciais.
- 🔗 [Deploy](https://piaui-for-the-word.vercel.app/) 

---

### 🦟 Dengue Tracker *(Vigilância Epidemiológica Geoespacial)*
> Aplicação full-stack para monitoramento epidemiológico combinando geolocalização, séries temporais e mapas de calor interativos.

- **Stack:** `Python` `PostgreSQL` `React` `Leaflet` `REST API`
- **Arquitetura:** Modelagem relacional para séries temporais e endpoints RESTful para consumo analítico integrado a mapas interativos.
- 🔗 [Deploy](https://dengue-tracker.vercel.app/) 

---

### 📊 Plataforma de Pesquisa Eleitoral & Análise de Dados
> Sistema analítico para coleta, consolidação e visualização estatística de cenários e intenções de voto.

- **Stack:** `Python` `React` `Data Analytics`
- **Arquitetura:** Pipeline de tratamento e cruzamento de dados demográficos e regionais com geração de painéis interativos e indicadores comparativos.
- 🔗 [Deploy](https://pesquisa-eleitoral-nu.vercel.app/)

---

### 📐 Laboratório da Parábola *(Simulador Matemático Interativo)*
> Aplicação web interativa para exploração visual e analítica de funções quadráticas e propriedades geométricas da parábola.

- **Stack:** `Python` `Streamlit` `Matemática Computacional`
- **Arquitetura:** Manipulação dinâmica de coeficientes em tempo real com cálculo automatizado de vértice, foco, diretriz, raízes e plotagem gráfica para apoio didático.
- 🔗 [Deploy](https://laboratorio-da-parabola.vercel.app/)
